# Cactus LeadPage Sprint
One focused enquiry page, offered as an existing Cactus Digital Media service.

## Offer
- US$300 fixed project fee for international clients; NGN150,000 for Nigerian clients.
- 50% deposit after scope agreement, balance before handover.
- One responsive page (up to six sections), supplied-copy refinement, one contact route, basic metadata/accessibility, one revision, compatible-hosting deployment and source handover.
- Target delivery: five business days after scope, deposit, content and access.
- Hosting, domains, paid tools, custom backend/CRM/AI/payment integrations and sales guarantees are excluded.

## Run
Open index.html directly, or serve this directory with any static web server. No build step, dependencies, tracking or API keys.
The enquiry form opens the visitor's mail client; it does not submit or store data. Email and WhatsApp provide alternate contact routes.

## Find → Flip → Fix
The supplied video's on-screen framework is Find → Flip → Fix: find an existing money-making category, take a new direction, and address weaknesses/complaints. It explicitly says “not copying.”
Here the category is website design; the change is a small fixed-scope page instead of a full redesign; the intended fix is an unclear enquiry journey. These are original layouts, not copied competitor code or branding.
